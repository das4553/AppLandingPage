# Mind Haven - Meditation App Landing Page

A modern, responsive, one-page landing page for a meditation and mindfulness app. Features smooth scroll animations, interactive sections, and a contact form, making it ideal for promoting wellness apps or similar products.

## **Features**

- Fully responsive design (desktop, tablet, mobile)
- Hero section with animated images and call-to-action
- About section with smooth scroll animations
- Features/services section with animated cards using **GSAP**
- FAQ section with collapsible answers
- Testimonials section
- Contact form integrated with **EmailJS** (requires your own EmailJS setup)
- Footer with social links and contact info
- Scroll-triggered animations powered by **GSAP** and **ScrollTrigger**
- Optimized for SEO and accessibility

## **Setup Instructions**

1. **Clone or unzip** the project folder.
2. Open `index.html` in a browser, or use VS Code with **Live Server** for local preview.
3. Update any **images** in `/assets/images/` as needed.
4. Modify **text content** directly in `index.html`.
5. Customize styles in `/css/style.css` and `/css/responsive.css`.
6. Optional: Adjust GSAP animations in `/js/gsap.js`.
7. If using the contact form:
   - Sign up for **EmailJS** (https://www.emailjs.com/)
   - Replace the EmailJS service ID, template ID, and user ID in `contact.js`.

---

## **Customization**

- **Colors:** Change in `style.css` under root variables or section-specific classes.
- **Fonts:** Currently using FontAwesome icons and system/default fonts; can add Google Fonts.
- **Images:** Replace all images in `/assets/images/`. Make sure to update alt texts in HTML for SEO.
- **Animations:** Adjust durations, easing, or triggers in `gsap.js`.
